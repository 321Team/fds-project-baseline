### 가입 미완료 사유 — 확인 사실과 미확정 원인

- **확인 사실:** CP2·CP3는 `/var/lib/kubelet/config.yaml` 부재로 kubelet이 반복 종료되며, Node 가입 완료 증적이 없다. CP1 Ready/API 정상과 3CP HA 완료는 별개다.
- **CP2 잔여 구성:** API server·controller-manager·scheduler 매니페스트 3개와 이전 이미지 Pull 성공 기록이 있어 일부 부트스트랩 구성이 남아 있다. etcd 매니페스트는 없으며, 생성 주체·중단 phase·etcd 데이터/등록 상태는 미확인이다. CP3의 매니페스트 부재만으로 과거 join 시도가 없었다고 단정하지 않는다.
- **통신 보완 필요:** CP 간 필수 통신 허용 누락은 확인됐다. 이전 연결 시험과 firewall reject는 방화벽 관여를 뒷받침하지만, 이를 원래 `context deadline exceeded`의 유일한 원인으로 확정하지 않는다.
- **증적 한계:** 원래 join stdout은 확보되지 않았다. CP2·CP3 kubelet journal은 마지막 1,500줄로 제한되어 전날 join 시점을 포함하지 않는다. Node 목록만으로 etcd 멤버 수도 한 개라고 단정하지 않는다.
