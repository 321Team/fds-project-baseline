# 고정 설명·선택 카드에 대한 렌더 상태 보충

2026-10-16 KST · CODEX_ASSISTED · 파생 제안 문서 / 공식 정본 미채택

이 보충은 [설명 원본](payload/current/P1_AS_BUILT_CANDIDATE.md)과 [기존 A1 카드](../../A1_UPDATED_DECISION_CARD.md)의 렌더 상태만 갱신해 읽기 위한 것이다. 기술 값·증적 시점·AC·실효 범위를 변경하지 않는다.

| 과거 원문 | 현재 읽을 상태 | 여전히 남는 판단 |
|---|---|---|
| “그림 파생본은 아직 만들지 않았고 MMD 렌더 검증도 미실행” | 논리/물리 SVG·PNG 생성 및 실제 시각 검토 완료 | 공식 배포 형식 선택 |
| “파생본 생성·렌더 QA 미실행” | 원본 논리도의 가림 4곳·라벨 경계 겹침 발견, 별도 제안에서 해소. 물리도 통과 | 원본 논리도 그대로의 채택과 수정안 채택을 구분 |
| “아직 전체 As-built 승인·render QA를 받지 않았다” | render QA는 완료. 전체 As-built 승인은 미결정 | 아키텍처 승인·원본 채택·정본 발행·Freeze |
| 설명 원본의 작업 범위에 포함된 “렌더 검증은 수행하지 않았다” | 설명 원본 작성 당시의 이력이다. 후속 렌더 검증은 별도 QA 결속으로 수신 | 과거 기록을 현재 미실행 상태로 재사용하지 않음 |

원본 논리 MMD `30937358…`와 제안 `829890b4…`의 차이는 보이지 않는 배치 제약 `EXP ~~~ API`, `HBR ~~~ LB`, `RUN ~~~ PM`, `DB ~~~ HBR` 4개뿐이다. 원본 문구 전체는 제안의 변경 없는 prefix다. 표시 노드 21개·연결선 22개·라벨 문구의 동일성은 기존 [SOURCE_SEMANTICS_CHECK](payload/current/render-validation-20261016/SOURCE_SEMANTICS_CHECK.json)로 확인돼 있다. 이 네 선은 실제 통신 관계를 추가하지 않는다.

Mermaid 기본 렌더만으로 남는 라벨 겹침은 필수 renderer가 `PM → MGW`의 remote-write 라벨을 SVG 좌표 `(160, 12)`만큼 옮겨 해소한다. 문자열과 연결선의 모양은 바꾸지 않는다. [최종 제안 기하 검사](payload/current/render-validation-20261016/PROPOSAL_GEOMETRY_REVIEW.json)는 노드 가림·라벨/노드·서로 다른 라벨 겹침 0건을 기록한다. [실제 시각 검토](payload/current/render-validation-20261016/VISUAL_REVIEW.md)의 확대 이미지 확인과 읽기 한계도 함께 유지한다.

확대 가능한 SVG가 검토·배포 파생본 권장안이다. PNG는 이번 QA 확인용이며 PDF는 생성하지 않았다. 일부 연결선 교차와 기본 테마의 반투명 라벨 배경은 남아 있어 SVG 확대/원래 크기 PNG로 읽는다. 이를 모든 배포 크기에서 무조건 읽기 좋다는 보증으로 바꾸지 않는다.

설명 원본을 채택할 때는 이 보충을 함께 채택하거나, 이 내용만 설명 정본에 통합한 정확한 후속본을 다시 결속해야 한다. 이번에는 원본 설명 파일을 직접 수정하지 않았다.
