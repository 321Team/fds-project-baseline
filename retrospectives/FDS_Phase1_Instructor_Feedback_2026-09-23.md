# FDS 1차 평가 강사 피드백 — 2026-09-23

- 출처: 1차 평가 강사 피드백
- 성격: **기록 전용.** 담당·기한·완료 기준을 지정하지 않으며 티켓·WBS·일정에 반영하지 않는다.

## 1. 산출물 제출 가이드 (3조 우수사례)

외부 제출물 기준이며 이 저장소의 폴더 구조와는 무관하다.

- 3조 폴더 분류 방식을 참고해 4개 항목으로 구조화해 제출
  1. 발표 자료 (PPT 및 PDF 포맷 포함)
  2. 프로젝트 세부사항 보고서
  3. 코드 (실제 작업 수행 코드)
  4. 시연 동영상
- 발표 자료는 PPT·PDF 두 형식 제공

## 2. 발표 자료

- 보완: 이론 중심 기술에서 벗어나 실제 사용 코드 예시 일부 포함 (예: Ansible YAML)
- 유지: 1차 발표의 데이터·성과 수치화 표시 방식 (우수 평가)

## 3. 2차 프로젝트 개발 및 협업 방향

- 스토리라인 확장: 현 결과물에서 한 단계 확장된 심화 콘텐츠 추가
- 사전 소통 강화: 개발·작업 착수 전 팀원 간 충분한 사전 논의·조율 선행
